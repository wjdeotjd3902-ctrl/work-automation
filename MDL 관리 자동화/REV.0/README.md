## 사용

독립 스킬 3개입니다. 각 폴더의 SKILL.md와 scripts·references·agents를 함께 설치합니다. 플러그인 패키지는 아닙니다. Classic Outlook과 Excel 작업 환경이 필요하며 실제 업무 실행은 각 스킬의 승인 규칙을 따릅니다.

## 개정 관리

REV.0은 초기 기준본입니다. 다음 변경은 REV.1에 저장하고 변경 이유를 기록합니다.

## 공개본 범위

실제 프로젝트 프로필은 제외하고 문서번호·프로젝트명·검토기관명은 예시값으로 바꿨습니다. 실제 사용 시 현재 MDL에서 프로젝트 프로필을 생성하고 검증하세요. 원본 스킬 및 실제 프로필은 로컬에 보존했습니다.

문서 구조·내부 참조·보조 파일을 확인했으며 실제 메일·Excel 변경 작업은 실행하지 않았습니다.
