# MDL 자동화 Lessons Learned

메일 분류, 첨부 저장, MDL 갱신 과정에서 사용자가 보고한 문제와 조사·해결·검증 이력을 누적하는 파일 기반 데이터베이스입니다.

## 오류 목록

| ID | 제목 | 구분 | 상태 | 최종 수정 | 기록 |
|---|---|---|---|---|---|

현재 접수 0건. 과거 기억이나 예제를 실제 오류로 등록하지 않습니다.

## 기록 방법

1. `mdl-lessons-learned` 스킬에 증상이나 오류 메시지를 전달합니다.
2. 기존 사례와 비교한 뒤 `records/LL-YYYYMMDD-NNN.md`에 기록하고 위 목록을 갱신합니다.
3. 해결안과 실제 적용·검증 결과를 구분해 같은 기록에 누적합니다.

상태: `접수` → `조사중` → `해결안 제시` → `적용완료` → `검증완료`. 정보·권한·환경이 부족하면 `보류`, 재발하면 `재발`로 기록합니다. 해결안을 찾았다는 이유만으로 검증완료로 바꾸지 않습니다.

공개 저장소에는 익명화한 기술 정보만 저장합니다. 원본 메일, 첨부파일, 문서번호, 개인 이름·주소, 내부 경로, 인증정보는 포함하지 않습니다.
